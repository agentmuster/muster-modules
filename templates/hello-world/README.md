# Hello world (template)

Copy this folder to `packages/<your-module-id>`, then change the `id` in `muster-module.json` to match the folder name. It shows one setting, an action with a preview and an agent tool. Its tests use the SDK's fake context, so they need no account or network.

To try it in Muster: ⋮ → Modules → Browse → Install from a link, and give this folder's path.
